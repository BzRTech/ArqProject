Design system · v1.0

Prancheta

Uma interface que recua para o desenho aparecer. Paleta de materiais, linhas de 1px, medidas em fonte mono e um serifado para dar o tom de prancha de apresentação.

I.
Silêncio
O desenho é o protagonista. Painéis neutros, sem cor de marca competindo com a planta.
II.
Precisão
Medidas e códigos sempre em mono. Bordas de 1px, grid de 4px, alinhamento rigoroso.
III.
Materialidade
Cores tiradas do ateliê: papel, grafite, argila, sálvia, carvalho e travertino.
